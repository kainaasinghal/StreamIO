# StreamIO

rdbms project- streaming platform management system

This repository contains the existing Streamio React/Vite frontend, FastAPI backend, MySQL schema/import utility, and the supplied dataset.

- Application and setup instructions: [streamio (1)/README.md](streamio%20(1)/README.md)
- Source dataset: [streamio_dataset/final_pkg/README.md](streamio_dataset/final_pkg/README.md)

The backend connects to MySQL using the local, ignored `streamio (1)/backend/.env` file. Never commit real database credentials. The repository is intended to remain private because the supplied demo dataset documentation contains sample login details.
